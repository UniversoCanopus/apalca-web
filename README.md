# APALCA Web

Prototipo de un portal regional de planetarios de América Latina y el Caribe. El piloto se prepara para una revisión en marzo de 2027. Su adopción como portal oficial queda sujeta a la decisión de APALCA.

## Alcance del piloto

- Directorio de planetarios con búsqueda, filtros por país, mapa y fichas institucionales.
- Sección del encuentro de Medellín 2027.
- Hoja de ruta para el desarrollo del portal y la validación del directorio.

El punto de partida técnico es una demo HTML que funciona sin conexión. Las fichas de prueba sirven para evaluar el directorio. La validación de membresías y los criterios de publicación corresponden a APALCA. El archivo institucional se plantea como un espacio separado, bajo control de la asociación.
